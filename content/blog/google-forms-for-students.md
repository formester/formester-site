<p style="font-size: inherit;">Google Forms is a simple way to give students a quiz that grades itself, collect an exit ticket, run a morning check-in, take attendance, or collect a permission slip. Build the form once, turn on quiz mode when you need a score, and share it through Google Classroom or a link.</p>

<p>The tool stays the same for each use. What changes are a few settings: whether the form grades answers, whether it records who responded, whether a student can respond more than once, and what students see after submitting. Get those settings right and the rest is just writing the questions.</p>

<p>This guide covers seven common ways to use Google Forms with students, the settings each one needs, how to build a self-grading quiz, how to hand it out through Google Classroom, and what Google Forms cannot do for a class.</p>

<div class="tldr">
<p><strong>Quick answer</strong></p>
<ul>
<li><strong>Good for:</strong> quizzes with an answer key, exit tickets, check-ins, attendance, permission slips, homework hand-in and end-of-unit feedback. All are free with a Google account.</li>
<li><strong>How to hand it out:</strong> Use a Google Classroom quiz assignment if your school has Google Workspace for Education. Otherwise, share the responder link or a QR code. Classroom also adds locked mode on managed Chromebooks and grade importing.</li>
<li><strong>What it cannot do:</strong> Google Forms does not have a timer, a random question bank, or locked mode outside a school-managed Chromebook. One response per student and file uploads also require a Google sign-in.</li>
</ul>
</div>

<h2 id="uses">What can you use Google Forms for with students?</h2>

<p>Seven uses cover most classroom needs. Each one is still a regular Google Form plus one or two important settings. That setting is what makes the form work for the task.</p>

<h3>1. A quiz that grades itself</h3>

<p>Turn on <strong>Make this a quiz</strong> in Settings, then set the answer key and points for each question. Google Forms can automatically grade Multiple choice, Checkboxes, Dropdown, Short answer and grid questions as soon as a student submits. Paragraph answers still need to be graded in the Responses tab.</p>

<p><strong>Setting:</strong> The setting that matters is Release grades. Choose Immediately after each submission for practice. Choose Later, after manual review if you want to review written answers before students see their scores. That option requires Collect email addresses to be switched on.</p>

<h3>2. An exit ticket</h3>

<p>Keep it simple: three questions at the end of a lesson. Ask students what they learned, what question they still have, and how confident they feel on a 1-to-5 Linear scale. Keep it short enough to finish before the bell.</p>

<p><strong>Setting:</strong> There is no special setting. Leave quiz mode off. If you want to follow up with a named student, collect their email address. Then check the Summary tab before the next lesson.</p>

<h3>3. A daily check-in</h3>

<p>Use a mood scale, a Multiple choice question about how the week is going, and an optional Paragraph for anything a student wants you to know. You can use the same form every day. Make the title the name of the check-in and use the description to explain who reads the responses.</p>

<p><strong>Setting:</strong> The setting that matters is Collect email addresses. Verified records the school account automatically. Do not collect keeps the responses anonymous. Say which option you are using in the description, because students may answer differently depending on whether their response is tied to them.</p>

<h3>4. Attendance and sign-in</h3>

<p>Create a form with the student's name and a Dropdown for the class or period. Put a QR code on the board so students can open it quickly. Every response has a timestamp, so the connected Sheet can act as the register.</p>

<p><strong>Setting:</strong> Turn on Limit to 1 response if you want to stop students from signing in twice. Keep in mind that this requires a Google sign-in. Link the form to Sheets so the register updates as students submit.</p>

<h3>5. Permission slips and parent information</h3>

<p>Field trip permission, emergency contacts, photo consent and start-of-year information can all use the same basic setup: the student's name, a Checkboxes question for the consents, and a Short answer question for the parent's name as a signature line.</p>

<p><strong>Setting:</strong> Turn on Allow response editing so a parent can correct a phone number later. Set Collect email addresses to Responder input so the confirmation has an address to go to. A typed name is not an e-signature, so check what your school accepts.</p>

<h3>6. Homework and project hand-in</h3>

<p>Use a File upload question so students can attach a document, a photo of their work, or a video. Add a Dropdown for the assignment and a Short answer for the title. The uploaded files go into a Drive folder named after the form.</p>

<p><strong>Setting:</strong> File upload questions require students to sign in to Google, and the files use the form owner's Drive storage, not the student's. Set the file count and size limits on the question.</p>

<h3>7. Course feedback</h3>

<p>At the end of a unit, ask students to rate the pace with a Linear scale, choose what helped most with Multiple choice, and explain what they would change with a Paragraph. Keep it anonymous by default. Students are more likely to write honestly when the form does not identify them.</p>

<p><strong>Setting:</strong> Leave Collect email addresses set to Do not collect and keep Limit to 1 response turned off. Say in the description that the feedback is anonymous.</p>

<h2 id="build">How do you make a Google Form for students?</h2>

<p>The example below is a short science quiz. A quiz uses most of the settings covered above, plus a few more. If you are making something that is not graded, skip the quiz setup step.</p>

<ol class="steps">
<li>
<h3>Start with a Blank form or an Education template</h3>
<p><img src="https://formester-strapi.s3.ap-south-1.amazonaws.com/23766cf53a4e09cf_gforms-st-step1-gallery-blank.gif" alt="The Google Forms template gallery with the Education row of Blank Quiz, Exit Ticket, Assessment, Worksheet and Course Evaluation, then Blank form opening" loading="lazy"></p>
<p>Open <a href="https://forms.google.com" target="_blank" rel="noopener">forms.google.com</a> and select <strong>Template gallery</strong>. The Education section includes Blank Quiz, Exit Ticket, Assessment, Worksheet and Course Evaluation templates, with the relevant settings already turned on. Blank form starts with one empty question and no special settings enabled.</p>
</li>
<li>
<h3>Turn on Make this a quiz</h3>
<p><img src="https://formester-strapi.s3.ap-south-1.amazonaws.com/36095f1b217442a3_gforms-st-step2-make-quiz.gif" alt="Switching on Make this a quiz in the Google Forms Settings tab, which adds Release grades and Respondent settings" loading="lazy"></p>
<p>Open <strong>Settings</strong> and turn on <strong>Make this a quiz</strong>. Each question now has an Answer key link and a points box, and the Responses tab gets a score summary. It is best to do this before writing the questions so you can set the answer key as you go.</p>
</li>
<li>
<h3>Write the questions and set the answer key</h3>
<p><img src="https://formester-strapi.s3.ap-south-1.amazonaws.com/c94abc98e76d1216_gforms-st-step3-answer-key.gif" alt="Typing a Multiple choice question in Google Forms, opening Answer key, ticking Mercury as correct and setting 2 points" loading="lazy"></p>
<p>Add a question, choose <strong>Multiple choice</strong>, enter the options, then open <strong>Answer key</strong>. Select the correct option and set the points. You can also add answer feedback if you want a student who gets the question wrong to see an explanation or video. Short answer questions can use a list of accepted answers.</p>
</li>
<li>
<h3>Choose what students see</h3>
<p><img src="https://formester-strapi.s3.ap-south-1.amazonaws.com/7706d80475eec0d2_gforms-st-step4-release-grades.gif" alt="Choosing Later, after manual review under Release grades and switching off Correct answers and Point values in Google Forms" loading="lazy"></p>
<p>Under <strong>Release grades</strong>, choose Immediately after each submission or Later, after manual review. Under <strong>Respondent settings</strong>, decide whether students can see missed questions, correct answers and point values. For a test, hide all three until you release the grades.</p>
</li>
<li>
<h3>Decide who can respond</h3>
<p><img src="https://formester-strapi.s3.ap-south-1.amazonaws.com/0d5a7a284ba3995d_gforms-st-step5-who-responds.gif" alt="The Responses settings in Google Forms with Collect email addresses on Verified and Limit to 1 response switched on" loading="lazy"></p>
<p>Under Responses, set <strong>Collect email addresses</strong> to Verified so each score is tied to the student's account, and turn on <strong>Limit to 1 response</strong>. School accounts can also use Restrict to users in your domain. Keep that setting on for a class and turn it off when parents need access.</p>
</li>
<li>
<h3>Publish and hand it out</h3>
<p><img src="https://formester-strapi.s3.ap-south-1.amazonaws.com/884db3967ae39737_gforms-st-step6-publish-link.gif" alt="Publishing the Google Forms quiz and copying the shortened responder link" loading="lazy"></p>
<p>Click <strong>Publish</strong> and copy the responder link. You can shorten the URL or make a <a href="/blog/how-to-make-a-qr-code-for-a-google-form/">QR code</a> for the board. If your school uses Google Classroom, attach the form to a quiz assignment instead.</p>
</li>
</ol>

<h2 id="classroom">How do you assign a Google Form to students in Google Classroom?</h2>

<p>Google Classroom requires a Google Workspace for Education account provided by the school. With it, a Google Forms quiz becomes an assignment with a due date and two useful options that a plain link does not provide.</p>

<p>In Classroom, open the class, select <strong>Classwork</strong>, then <strong>Create</strong> and <strong>Quiz assignment</strong>. Classroom creates a blank Google Forms quiz and attaches it. Open the attachment to build the quiz, or use Create and Assignment if you already have a form in Drive.</p>

<p><strong>Locked mode on Chromebooks:</strong> Students using school-managed Chromebooks cannot open other tabs while the quiz is open. You also get an email if a student leaves the quiz and comes back. Students on other devices cannot open a locked-mode quiz, so turn it off for classes using mixed devices.</p>

<p><strong>Grade importing:</strong> Turn it on when you create the assignment. After the due date, open the assignment and click <strong>Import grades</strong>. The Forms scores are added to the Classroom gradebook. The two sets of grades remain separate, so if you regrade in Forms, import the grades again to update Classroom.</p>

<p>If you are not using Classroom, the responder link works for any student who has the URL. Collect email addresses if you need to identify respondents, and share a shortened link in the class chat.</p>

<h2 id="results">How do you read what students answered?</h2>

<p>The Responses tab has three views. <strong>Summary</strong> shows frequently missed questions, a chart for each question with the correct answer marked, and the average, median and range of scores. This is the view to check before the next lesson.</p>

<p><strong>Question</strong> view lets you grade one question across the whole class. You can mark a group of answers correct, give partial points, or add the same feedback to everyone who wrote the same thing.</p>

<p><strong>Individual</strong> view shows one student at a time, with a points box and feedback field under each answer. If grades are set to release later, you can release the score from the top of each response. Select students and click Send emails and release. Linking to Sheets puts every response into a spreadsheet, which can then feed into an <a href="/blog/how-to-turn-google-forms-into-student-assessment-dashboard/">assessment dashboard</a>.</p>

<h2 id="limits">What Google Forms cannot do for students</h2>

<ul>
<li><strong>No timer:</strong> There is no countdown or per-student time limit. A close date ends the quiz for everyone at once. Per-student timing requires an <a href="/blog/how-to-add-a-timer-to-your-google-quiz-includes-latest-alternative-works-without-add-ons-2023/">add-on or another tool</a>.</li>
<li><strong>Locked mode is Chromebook-only:</strong> It requires a school-managed Chromebook and a Classroom assignment. On a phone, laptop, or personal Chromebook, the quiz behaves like a normal web page alongside other tabs.</li>
<li><strong>One response needs a sign-in:</strong> Limit to 1 response only works for students signed in to Google. That makes it unsuitable for a class using a shared device or for a parent without a Google account.</li>
<li><strong>No question bank:</strong> Every student gets the same questions. The available randomisation is Shuffle question order in Presentation settings and Shuffle option order on an individual question.</li>
<li><strong>File uploads use your Drive:</strong> Uploaded files are stored in the form owner's Drive and require the student to sign in. That means a file hand-in form cannot be anonymous.</li>
<li><strong>No partial credit in the answer key:</strong> A Checkboxes question is correct only when every correct option is selected and nothing else is selected. Partial points have to be given manually in Question view.</li>
</ul>

<details><summary>Can Google Forms grade automatically?</summary><div>Yes, in quiz mode. Multiple choice, Checkboxes, Dropdown, Short answer and grid questions can be marked against the answer key as soon as a student submits. These measures do not stop a student from using a second device, so Google Forms quizzes are better suited to practice than high-stakes exams.</div></details>
