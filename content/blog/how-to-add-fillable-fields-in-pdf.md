## First, choose the output you need

People use fillable PDFs for a few different jobs. The right route depends on what you want to send and what you want back.

### Keep the PDF as a file

Choose this when someone must download, complete and return the same document. Government forms, contracts and documents with a fixed layout often work this way.

This guide covers that job. You will add interactive fields to the PDF itself and download the finished file.

### Collect answers online and generate the PDF later

[Convert the PDF into an online form](/features/convert-pdf-to-fillable-form/) when you need to collect the same information from many people. They complete a web form, and you keep each response in one dashboard. On the Business plan, Formester can also [fill your original PDF after each submission](/features/create-fillable-pdf-forms/).

Read [how to create an online form from a PDF](/blog/create-online-form-from-pdf/) if you need this workflow.

### Fill a PDF someone sent you

You do not need to add fields when the PDF already has them. Follow the guide to [fill out and save a PDF form](/blog/how-to-fill-out-pdf-forms-an-easy-step-by-step-guide/) instead.

Use clear field names before you download the file. A name such as `client_name` is easier to understand later than `text_1`. Field names also matter when another tool reads or fills the PDF.

Use <strong>Test fill</strong> and press Tab to check how a keyboard moves through the fields before you download the PDF.

## Other ways to add fields to a PDF

The free creator works well for a digital PDF when you want to place the fields yourself. Another tool may fit better when the file is scanned, locked or already part of a paid document workflow.

### Adobe Acrobat

Adobe Acrobat Pro can detect likely fields in a digital file or scanned document. Open **Tools**, choose **Prepare Form**, select the file and review the fields Acrobat adds.

Acrobat is the better route when you need OCR for a scan or need to work with a restricted PDF. It requires a paid plan. Check every detected field before sending the file because OCR and field detection can misread a busy page.

### Sejda

Sejda lets you upload a PDF, add fields and download the result. Its published free limits are 200 pages or 50 MB and three tasks per hour. The file is uploaded to Sejda and deleted after two hours, so check your privacy requirements before using it for client or employee documents.

### iLovePDF and PDF24

iLovePDF and PDF24 also provide browser-based PDF form tools. Their limits and field support differ. Use the full [PDF form creator comparison](/blog/best-pdf-form-creator/) if you want to compare pricing, privacy and output formats.

### Microsoft Word

Word makes sense when you are creating the document from scratch. Add the controls in Word, protect the document and export it as a PDF. It is not the quickest route for a PDF that already exists. Follow the separate guide to [make a fillable form in Word](/blog/how-to-make-a-fillable-form-in-word/) for those steps.

## Fix common PDF field problems

### The boxes are visible, but nobody can type in them

The boxes may be part of the page design rather than real form fields. This happens with PDFs exported from design tools and with scanned paperwork. Add an interactive field over each blank area, then test the file in a PDF viewer.

### The PDF is password protected

A PDF can block changes even when you can open and read it. Ask the document owner for an editable copy or the owner password. Do not remove restrictions from a file you do not control.

### The fields look different after download

PDF viewers do not render every field in exactly the same way. Download the finished file and test it in the viewer your recipient will use. Check signatures in Adobe Acrobat, and check text size and field borders in at least one browser viewer.

### The PDF is a scan

A scan is an image of a page. Formester can place fields over it manually, but it cannot read the printed labels or detect blank areas. Use an OCR tool first when you want software to recognise the page content automatically.

## When a web form works better

A fillable PDF keeps the document layout. It does not give you a response dashboard or remind people to finish the form. Completed files usually come back through email, and someone still needs to organise them.

Use an online form when the same process repeats. A client intake form is a good example. You send one link, see which responses are complete and store the answers together. Formester can then create a filled copy of the original PDF after each submission when you still need the document.
