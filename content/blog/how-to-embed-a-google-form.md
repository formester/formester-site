![Cover art for a guide to embedding a Google Form in a website or an email](https://formester-strapi.s3.ap-south-1.amazonaws.com/6af88fe3a2104dc2_how-to-embed-a-google-form-cover.png)

<p style="font-size: inherit;">Embedding a Google Form puts it on your own page, so people fill it in without leaving your site for a docs.google.com address. Google gives you a piece of HTML called an iframe. Any site builder that accepts HTML can show it.</p>

<p>This guide covers how to embed a Google Form with the current Embed HTML option and how to make the iframe fit on a phone. It also covers sending the form inside an email. The last section fixes the form that shows a blank box instead of loading.</p>

<div class="tldr">
<p><strong>Quick answer</strong></p>
<ul>
<li><strong>Your own website or HTML page:</strong> publish the form and click the three-dot <strong>More</strong> menu. Choose <strong>Embed HTML</strong> and copy the code. Paste it where the form should appear.</li>
<li><strong>A site builder:</strong> paste the same code into a Custom HTML block in WordPress, Embed HTML in Wix, a Code block in Squarespace, or an Embed element in Webflow. Google Sites has its own Forms option under Insert, with no code.</li>
<li><strong>An email:</strong> tick <strong>Notify people</strong> when you share or publish the form. Google sends the form in the email, but many mail apps show only a link, so add the responder link too.</li>
</ul>
</div>

<h2 id="code">How do you embed a Google Form in a website?</h2>

<p><img src="https://formester-strapi.s3.ap-south-1.amazonaws.com/b17a6d554d73f213_google-forms-embed-html.gif" alt="Copying the Google Forms embed code from Embed HTML after changing the iframe height to 820 pixels" loading="lazy"></p>

<p>Google moved the embed option when it added the Publish button. It used to sit behind Send. It is now in the More menu. The form also has to be published before the embed loads for anyone but you.</p>
<ol class="steps">
<li>
<h3>Publish the form</h3>
<p>Click <strong>Publish</strong> in the top right. Click <strong>Manage</strong> next to Responders and check that General access is <strong>Anyone with the link</strong>. <a href="https://support.google.com/docs/answer/2839588" target="_blank" rel="noopener">Google's documentation</a> says responders cannot open an unpublished form. In an embed, that shows up as a permission message where the questions should be.</p>
</li>
<li>
<h3>Open Embed HTML</h3>
<p>Click the three-dot <strong>More</strong> menu in the top right of the editor and choose <strong>Embed HTML</strong>. If your account still shows a Send button instead of Publish, the same option is the angle-bracket icon inside Send.</p>
<!-- IMAGE: Google Forms editor, three-dot More menu open, Embed HTML item highlighted | ALT: The Google Forms More menu open in the top right of the editor with Embed HTML highlighted -->
</li>
<li>
<h3>Set the width and height</h3>
<p>The dialog shows the iframe code with width and height fields. Set the width to what your page column allows, and the height to the full length of the form. Google does not resize the iframe later, so a short height means the form scrolls inside its own box.</p>
<!-- IMAGE: Embed HTML dialog, iframe code visible, width and height inputs, Copy button | ALT: The Embed HTML dialog in Google Forms showing the iframe code with width and height fields and a Copy button -->
</li>
<li>
<h3>Click Copy</h3>
<p>Click <strong>Copy</strong>. The code looks like this, with your own form ID in the address:</p>
<pre><code>&lt;iframe src="https://docs.google.com/forms/d/e/FORM_ID/viewform?embedded=true" width="640" height="1200" frameborder="0" marginheight="0" marginwidth="0"&gt;Loading…&lt;/iframe&gt;</code></pre>
</li>
<li>
<h3>Paste the code into your page</h3>
<p>Paste the iframe into the HTML of your page where the form should appear, or into the HTML block of your site builder. The next two sections cover both.</p>
</li>
</ol>

<h2 id="html">How to embed a Google Form in HTML</h2>

<p>On a hand-coded page, paste the iframe where the form should appear. That works on desktop as it is. The problem is phones. The iframe has a fixed pixel width, so a 640-pixel box on a 390-pixel screen gets cut off.</p>
<p>Wrap it in a container and let the width follow the container instead:</p>
<pre><code>&lt;div style="max-width:720px;margin:0 auto;"&gt;
  &lt;iframe src="https://docs.google.com/forms/d/e/FORM_ID/viewform?embedded=true"
    style="width:100%;min-height:1400px;border:0;"&gt;Loading…&lt;/iframe&gt;
&lt;/div&gt;</code></pre>
<p>The width now shrinks to the screen. The height still cannot follow the form. The form loads from Google's domain, so your page cannot measure it. Set the min-height a little taller than the form on a phone, where the questions wrap onto more lines. Adding or removing a question later changes the length, so check the page again after you edit the form.</p>

<h2 id="builders">How do you embed a Google Form in a site builder?</h2>

<p>Every builder has a block that accepts raw HTML. Paste the iframe from the steps above into that block. The wrapper trick works in all of them, since the block passes the HTML through as it is.</p>

<h3>WordPress</h3>
<p>In the block editor, add a <strong>Custom HTML</strong> block and paste the code. No plugin is needed. Page builders such as Elementor and Divi have an HTML widget that does the same job.</p>

<h3>Wix</h3>
<p>Click <strong>Add Elements</strong>, choose <strong>Embed Code</strong>, then <strong>Embed HTML</strong>. Paste the code into the element and drag the element to the size you want. Wix sizes the element separately from the iframe inside it, so check the mobile view before you publish.</p>

<h3>Squarespace</h3>
<p>Add a <strong>Code</strong> block to the section and set its type to HTML. Paste the code. The block takes the width of the column it sits in.</p>

<h3>Webflow</h3>
<p>Drag an <strong>Embed</strong> element from the Components panel onto the page and paste the code. It renders when you publish.</p>

<h3>Google Sites</h3>
<p>Google Sites is the one place you do not need the code. Open the <strong>Insert</strong> panel and click <strong>Forms</strong>. Pick the form from your Drive. Google Sites places it and sizes it, and you can drag the corners to adjust.</p>

<h2 id="email">How do you embed a Google Form in an email?</h2>

<p>Google can put the form itself inside an email, so the person answers without opening a page. It happens when you share or publish the form with <strong>Notify people</strong> ticked.</p>
<ol class="steps">
<li>
<h3>Publish the form</h3>
<p>Google only sends the email once the form is published. If you publish and notify responders at the same time, the email they get includes the form.</p>
</li>
<li>
<h3>Open Share and add the addresses</h3>
<p>Click <strong>Share</strong> in the top right and enter the people or groups who should get the form.</p>
</li>
<li>
<h3>Leave Notify people checked and click Send</h3>
<p>The box is on by default. Google sends each person an email with the form inside it.</p>
</li>
</ol>
<!-- IMAGE: Share dialog, two responder emails added, Notify people checkbox ticked, Send button visible | ALT: The Google Forms Share dialog with responder email addresses added and the Notify people box checked -->
<p><a href="https://support.google.com/docs/answer/2839588" target="_blank" rel="noopener">Google lists</a> the forms it cannot embed in an email: forms with a file upload question, a rating question, an image in a question or an option, or a secured quiz. Those forms arrive as a link.</p>
<p>Whether the form shows inside the message depends on the mail app that opens it. Many apps show a button or a link instead. Put the responder link in the message text as well, so everyone can open the form whatever their mail app does.</p>
<p>Formester's <a href="/features/embed-form-in-email/">embed form in email</a> option takes a different route. It puts the first question inside the email as clickable answers. The click opens the rest of the form with that answer already saved. The answer buttons render in Gmail and Outlook as well as Apple Mail and Yahoo Mail.</p>

<h2 id="fix">Why is the embedded Google Form not loading or not fitting?</h2>

<ul>
<li><strong>A blank box or a permission message.</strong> The form is not published, or responder access is Restricted. Click <strong>Publish</strong>, then <strong>Manage</strong>. Set General access to <strong>Anyone with the link</strong>. Our guide on <a href="/blog/how-to-enable-access-for-google-forms/">giving access to a Google Form</a> walks through every cause.</li>
<li><strong>An accounts.google.com refused to connect message.</strong> The form asks people to sign in, and Google's sign-in page cannot load inside an iframe. Limit to 1 response and Verified email collection both force a sign-in. So do a file upload question and Restricted responder access. Turn the setting off, or link to the form instead of embedding it.</li>
<li><strong>An empty box with a Content Security Policy error in the browser console.</strong> Your site blocks iframes from other domains. Add <code>frame-src https://docs.google.com;</code> to the policy, or ask whoever manages the site to.</li>
<li><strong>The form scrolls inside its own box.</strong> The height is too short. Open the form on its own and note how long it is. Set the min-height above that.</li>
<li><strong>The form is cut off on phones.</strong> The iframe has a fixed pixel width. Use the wrapper from the HTML section so the width follows the screen.</li>
<li><strong>The form ignores your site's colors and dark mode.</strong> Google Forms uses its own theme inside the iframe. The theme options change the colors and the font, not the layout or the buttons, and the form does not follow your site's dark mode. If the form has to match your site, use a form builder with its own embed. Our list of <a href="/blog/top-google-forms-alternatives/">Google Forms alternatives</a> compares the options.</li>
</ul>
